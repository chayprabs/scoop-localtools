# scoop-localtools

Scoop bucket for [localtools](https://tools.chaitanyaprabuddha.com): free offline tools that run on your machine.

```powershell
scoop bucket add localtools https://github.com/chayprabs/scoop-localtools
scoop install localtools-<tool>
```

Run `localtools-<tool>` to start it in your browser. Update with `scoop update localtools-<tool>`, remove with
`scoop uninstall localtools-<tool>`.

Manifests are generated from the localtools release manifest; please report problems at
https://github.com/chayprabs/localtools/issues.
